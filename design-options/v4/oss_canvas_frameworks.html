캔버스 · 플로우 오픈소스 후보 비교

지금 직접 만든 캔버스(카드 14개 + 화살표 + 주석 + 흐름 따라가기)를 대신할 수 있는 이미 만들어진 도구들을 찾았어요. 아래 그림은 각 도구가 어떤 모양인지 보여 주는 개념도이고, 실제 화면 캡처가 아닙니다.

우리가 필요한 것

카드(HTML)를 판 위에 배치기존 14개 카드 그대로 올릴 수 있어야 함
카드 사이 화살표흐름 1 → 2 → … 표현
팬·줌 + 미니맵피그마처럼 이동·확대, 전체 위치 확인
주석(노트)카드 옆 설명 + 핀
개인 무료 사용혼자 공부·복습용

결론: 1순위 React Flow, 대안 tldraw

  • React Flow (xyflow) — 카드를 {{노드}}로, 화살표를 {{엣지}}로 올리는 구조라 지금 만든 것과 가장 닮았어요. 미니맵·컨트롤·배경 격자가 기본 제공이고 MIT라 개인 사용에 제약이 없어요.
  • tldraw — "진짜 피그마·화이트보드 느낌"(자유 배치, 그리기)을 원하면 좋아요. 다만 오픈소스가 아니라 자체 라이선스예요. 개인 취미는 무료 Hobby 라이선스를 신청하는 방식이에요.
  • React를 안 쓰고 싶다면 같은 팀의 Svelte Flow, Vue라면 Vue Flow가 같은 방식이에요.
